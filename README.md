# FitLog - Workout Tracker

FitLog is a workout library project that I made for my Programming Hero Batch 14 assignment. From the home page, users can browse different exercises, check the workout details, and add exercises to their daily plan. They can also save workouts for later.

## 🔗 Links

- **Live Site:** https://ph-assingment-06-fit-log.vercel.app/
- **GitHub:** https://github.com/mustafizrahman055-hub/PH-Assingment-06-Fit-log

## Technologies Used

- Next.js
- React
- Tailwind CSS
- Lucide React
- React Hot Toast
- LocalStorage

## Features

- Workout library with exercises loaded from the API
- Workout details page with exercise information and instructions
- Add workouts to today's plan
- Save workouts for later
- Maximum 5 workouts can be added to today's plan
- My Plan page for managing planned workouts
- Mark a workout as done or remove it from the plan
- Sort workouts by duration, calories and rating
- Responsive design for mobile, tablet and desktop
- Plan and saved workouts stay after refreshing the page using LocalStorage
- Toast messages for different actions

## Run the Project Locally

First install the packages:

```bash
npm install
```

Then run the development server:

```bash
npm run dev
```

The project will be available at:

```text
http://localhost:3000
```
